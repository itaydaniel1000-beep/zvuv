# הפעלת המוח המלא על Windows

השרת מריץ על המחשב שלך את כל המוח של זבוב הפירות: 138,639 נוירונים ו־15 מיליון חיבורים מ־FlyWire. המודל הוא של Shiu et al. 2024. האתר שולח לשרת מה הזבוב רואה ומריח, ומקבל בחזרה את קצב הירי של הנוירונים. אם השרת לא רץ, האתר ממשיך לעבוד עם המוח הפשוט.

**מה צריך:** Windows 10 או 11, לפחות 8GB זיכרון (השרת משתמש בכ־2GB), וחיבור לאינטרנט בפעם הראשונה.

## שלב 1: התקנת פייתון
1. נכנסים ל־https://www.python.org/downloads/windows/ ומורידים את **Python 3.12** (הקובץ "Windows installer (64-bit)").
2. מריצים את קובץ ההתקנה. **חשוב:** לפני הלחיצה על Install Now, מסמנים V בתיבה **"Add python.exe to PATH"** בתחתית החלון.
3. לבדיקה: פותחים את תפריט התחל, מקלידים `cmd` ופותחים את **Command Prompt**. מקלידים:
   ```
   py --version
   ```
   אמור להופיע `Python 3.12.x`.

## שלב 2: הורדת הקוד
**הדרך הקלה (בלי git):**
1. נכנסים ל־https://github.com/itaydaniel1000-beep/zvuv
2. לוחצים על הכפתור הירוק **Code**, ואז על **Download ZIP**.
3. בתיקיית ההורדות: לוחצים על הקובץ `zvuv-main.zip` בכפתור הימני, בוחרים **Extract All** (חלץ הכל), ומחלצים למקום נוח, למשל `C:\zvuv`.

**עם git (אם מותקן):**
```
cd C:\
git clone https://github.com/itaydaniel1000-beep/zvuv.git
```
היתרון של git: בפעם הבאה מספיק להריץ `git pull` בתוך התיקייה כדי לקבל עדכונים.

## שלב 3: הפעלת השרת
1. פותחים את התיקייה `zvuv`, ובתוכה את התיקייה `brain_server`.
2. לוחצים לחיצה כפולה על **`start.bat`**.
   - אם Windows מציג "Windows protected your PC", לוחצים **More info** ואז **Run anyway**.
3. **בפעם הראשונה** זה לוקח כמה דקות. הסקריפט:
   - יוצר סביבת פייתון בתיקייה `.venv`
   - מתקין את Brian2 ושאר החבילות
   - מוריד את נתוני FlyWire (כ־140MB) לתיקייה `data\raw`
4. כשהשרת מוכן, מופיע בחלון:
   ```
   listening on ws://localhost:8765  (Ctrl+C to stop)
   network ready: 138639 neurons, 15091983 connections, ...
   ```
   אם Windows Firewall שואל אם לאפשר גישה לפייתון, אפשר ללחוץ Cancel. השרת עובד רק מול המחשב עצמו ולא צריך גישה מהרשת.
5. משאירים את החלון השחור פתוח. סוגרים אותו או לוחצים `Ctrl+C` כדי לעצור את השרת.

בפעמים הבאות מספיקה לחיצה כפולה על `start.bat`, והשרת עולה תוך כמה שניות.

## שלב 4: חיבור האתר
1. פותחים את https://itaydaniel1000-beep.github.io/zvuv/ ב־**Chrome** או **Edge** (גם Firefox עובד).
2. בכרטיס "המוח של זבוב" לוחצים **🔗 חבר למוח האמיתי**.
3. אם הדפדפן שואל אם לאפשר לאתר גישה למכשירים ברשת המקומית, מאשרים. כך האתר יכול לדבר עם `localhost`.
4. כשהחיבור מצליח:
   - הכותרת של הכרטיס משתנה ל"המוח המלא · 138,639 נוירונים"
   - מתחת לכפתור מופיע כמה מהר המוח רץ ואילו נוירונים הכי פעילים
   - בחלון השרת רצות שורות עם קצבי הירי של DN שמאל, DN ימין, DN קדימה ו־Giant Fiber
5. לחיצה על **⛔ נתק מהמוח האמיתי** מחזירה את האתר למוח הפשוט. אותו דבר קורה אוטומטית אם השרת נסגר.

## מה לצפות
- **המוח המלא איטי מהמציאות.** כל 50 אלפיות שנייה של מוח לוקחות למחשב בערך חצי שנייה עד שנייה וחצי. לכן הזבוב מגיב באיחור.
- **איום (הכפתור "איום"):** נוירוני LPLC2 ו־LC4 מפעילים את Giant Fiber בכ־150–180 ספייקים בשנייה, והאתר מפעיל את רפלקס הבריחה. זה עובד במודל המלא כמו בזבוב אמיתי. כדי לראות את זה, כדאי להפעיל את האיום כמה פעמים ברצף, כי האיחור ארוך מהאיום עצמו.
- **ריח:** אונת הריח "נדלקת" כולה תוך 10–20 אלפיות שנייה, ו־DNa02 השמאלי יורה לא משנה מאיזה צד הריח מגיע, ולכן הזבוב נוטה לפנות שמאלה. בדקנו את זה לעומק, בלי לשנות את החיבורים: המודל המלא לא מנווט לריח. הפירוט ב־`docs/odor-steering-findings.md`.
- **אור:** הפוטורצפטורים R7/R8 לא מגיעים לנוירוני ההיגוי בתוך 50 אלפיות שנייה, ולכן במוח המלא אין משיכה לאור.
- כל צעד מתחיל ממוח במנוחה, כמו ניסוי במאמר. בלי זה, אחרי ריח ראשון תאים באונת הריח נתקעים בירי של כ־300 ספייקים בשנייה ולא נרגעים.

## להאיץ פי 6 (לא חובה)
Brian2 יכול לתרגם את המודל לקוד C++, אבל לשם כך צריך מהדר:
1. מורידים את **Build Tools for Visual Studio** מ־https://visualstudio.microsoft.com/visual-cpp-build-tools/
2. בהתקנה מסמנים **"Desktop development with C++"** (כמה GB).
3. מפעילים מחדש את `start.bat`. בהפעלה הראשונה אחרי ההתקנה יש קומפילציה של כמה דקות, ואחריה כל צעד מהיר בהרבה.

בלי המהדר השרת עובד רגיל, רק לאט יותר. ייתכן שתופיע אזהרה על `cython`, ואפשר להתעלם ממנה.

## אפשרויות מתקדמות
מריצים מ־Command Prompt, מתוך התיקייה `zvuv`:
```
.venv\Scripts\python.exe brain_server\server.py --selftest
```
הפקודה בודקת את המוח בלי האתר: ריח משמאל ומימין, אור ואיום. לכל גירוי היא מדפיסה את קצבי הירי.

פרמטרים נוספים (אפשר להוסיף גם אחרי `start.bat` כשמריצים אותו מ־Command Prompt):

| פרמטר | מה הוא עושה |
|---|---|
| `--step 20` | צעדים קצרים יותר: תגובה מהירה יותר, פחות מדויק (ברירת מחדל 50) |
| `--max-rate 100` | קצב הירי של חיישן בעוצמה מלאה (ברירת מחדל 150, כמו במאמר) |
| `--memory` | המוח זוכר בין צעדים, במקום להתחיל כל צעד ממנוחה |
| `--target numpy` | לא מנסה לקמפל |

## תקלות נפוצות
- **"Python was not found"**: פייתון לא הותקן, או שלא סימנת "Add python.exe to PATH". מתקינים מחדש ומסמנים.
- **ההתקנה נכשלה באמצע**: מריצים שוב את `start.bat`. אם זה חוזר, מוחקים את התיקייה `.venv` ומנסים שוב.
- **הורדת הנתונים נכשלה**: מוחקים את התיקייה `data\raw` ומריצים שוב.
- **באתר כתוב "השרת לא רץ"**: בודקים שהחלון השחור פתוח ושכתוב בו `listening on ws://localhost:8765`, ואז לוחצים שוב על הכפתור.
- **"MemoryError" או מחשב שנתקע**: אין מספיק זיכרון. סוגרים תוכנות אחרות.
- **Safari**: לא מאפשר לאתר HTTPS להתחבר ל־`ws://localhost`. משתמשים ב־Chrome, Edge או Firefox.
