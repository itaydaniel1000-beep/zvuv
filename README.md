# 🪰 זבוב — מרכז שליטה

מרכז שליטה לרובוט בצורת זבוב. יש בו מוח מדומה בהשראת מפת המוח המלאה של זבוב הפירות (FlyWire, 2024).

## מה יש בפנים
- **זירת טיסה**: זבוב וירטואלי שאפשר להטיס. אפשר למקם בזירה ריח פרי 🍌, אור 💡 ואיום מתקרב.
- **המוח**: 16 קבוצות נוירונים, מהחישה (עיניים, אנטנות, LPLC2/LC4) דרך הגוף הפטרייתי, הקומפלקס המרכזי ו-Giant Fiber, ועד לשרירי הכנפיים. כל קבוצה היא אוסף של סוגי תאים אמיתיים מ-FlyWire, והחיבורים מחושבים מספירת הסינפסות האמיתית (ראו למטה). במצב „המוח שולט” הזבוב מתנהג לבד: מחפש ריח, נמשך לאור ובורח מאיומים.
- **שליטה ידנית**: שני ג׳ויסטיקים (עובדים גם במגע בטלפון), מקלדת (WASD / Q E / חיצים), חימוש, המראה, נחיתה, ריחוף ועצירת חירום (Esc).
- **כנפיים**: תדר, משרעת וכיול שמאל/ימין.
- **טלמטריה**: סוללה, גובה, מהירות, כיוון וגרף.
- **חיבור לרובוט**: סימולציה, WebSocket (WiFi) או USB (Web Serial).

## העלאה ל-Netlify
**הדרך הקלה:** להיכנס ל-https://app.netlify.com/drop ולגרור לשם את התיקייה `zvuv` (או את `zvuv.zip`). תוך כמה שניות מתקבלת כתובת.

**דרך GitHub:** להעלות את התיקייה לריפו, ואז ב-Netlify לבחור *Add new site → Import from Git*. אין צורך בפקודת build, הקובץ `netlify.toml` כבר מגדיר את הכל.

## חיבור הרובוט
הקוד לדוגמה נמצא ב-`firmware/zvuv_robot/zvuv_robot.ino`. הוא מתאים לארדואינו או ל-ESP32 עם שני סרוואים לכנפיים.
1. מתקינים את ספריית ArduinoJson ומעלים את הקוד ללוח.
2. באתר בוחרים **USB**, לוחצים **התחבר** ובוחרים את הפורט. זה עובד ב-Chrome או Edge במחשב.
3. האתר שולח פקודה 20 פעמים בשנייה, והרובוט מחזיר טלמטריה. אם הקשר נקטע לחצי שנייה, הרובוט עוצר מעצמו.

אם הרובוט שולח `sensors` בטלמטריה (`eyeL`, `eyeR`, `antL`, `antR`, `loom` בערכים 0–1), המוח באתר משתמש בחיישנים האמיתיים במקום בחיישנים הווירטואליים.

> שים לב: האתר ב-Netlify רץ ב-HTTPS, ולכן חיבור WebSocket חייב להיות `wss://`. לבדיקות עם `ws://` רגיל אפשר לפתוח את `index.html` ישירות מהמחשב.

## החיבורים מ-FlyWire
הרשימה `SYN` ב-`index.html` נוצרת אוטומטית (בין הסימונים `FLYWIRE:BEGIN` ו-`FLYWIRE:END`) על ידי הסקריפט `data/build_brain.py`:

```bash
pip install pandas pyarrow scipy
python data/build_brain.py        # מוריד כ-140MB לתיקייה data/raw בהרצה הראשונה
```

הסקריפט משתמש בנתוני FlyWire v783: רשימת החיבורים כפי שנארזה ב-Shiu et al. 2024, וסוגי התאים מ-Schlegel et al. 2024. הוא סופר סינפסות בין הקבוצות, קובע סימן לפי הנוירוטרנסמיטר (GABA וגלוטמט מעכבים), ומחפש מסלולים של 2–3 סינפסות כשאין קשר ישיר. הפירוט המלא נשמר ב-`data/flywire_brain.json`.

בדיקת התנהגות (ריח, אור, בריחה) בדפדפן בלי ממשק:

```bash
npm i -D playwright && node data/behavior_test.cjs
```

## המוח המלא (Shiu et al. 2024)
`brain_server/server.py` מריץ על המחשב את כל 138,639 הנוירונים של FlyWire (Brian2) ומדבר עם האתר דרך `ws://localhost:8765`. באתר לוחצים על **🔗 חבר למוח האמיתי**. אם השרת לא רץ, האתר ממשיך עם המוח הפשוט.

הוראות התקנה והפעלה צעד־צעד ל-Windows: `docs/brain-server-windows.md` (בקיצור: להתקין Python 3.12 וללחוץ פעמיים על `brain_server/start.bat`).

התוכנית המקורית: `docs/stage2-plan.md`. האם המוח המלא מנווט לריח (ממצא: לא, ולמה): `docs/odor-steering-findings.md`.
